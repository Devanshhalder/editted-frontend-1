# KarigarKart

A Flutter + Dart artisan marketplace demo with entirely local mock data. The app uses no backend or device plugins, so camera/gallery and voice recording are polished demo flows that work immediately on any Android emulator.

## Run in Android Studio

1. Open this project folder (the folder containing `pubspec.yaml`) in Android Studio with the Flutter plugin enabled.
2. Select an Android emulator.
3. Run `flutter pub get`, then press **Run** or execute `flutter run` in the project root.

The app entry point is `lib/main.dart`.

## Demo flow

Login with any email/phone and a 4-character password, then use **Add product**. The flow covers camera/gallery selection, voice description, language selection, simulated AI enhancement, AI listing generation, price review, editing, publishing and catalog/product details.
